텔레그램 알림 설정 가이드

1. 텔레그램 봇 생성

1) 텔레그램에서 @BotFather 검색 2) /newbot 명령 → 봇 이름 입력 3) 발급된 Bot Token 복사

2. Chat ID 확인

1) 텔레그램에서 @userinfobot 검색 2) /start → 표시되는 Chat ID 복사

3. 설정 파일 작성

cp baseball_config.example.yaml baseball_config.yaml baseball_config.yaml 에 아래 내용 입력: anthropic_api_key: "sk-ant-..." telegram: enabled: true bot_token: "여기에_봇_토큰" chat_id: "여기에_챗_ID"

4. 스케줄러 실행

python -m baseball_agent.scheduler 경기 1시간 전: 프리뷰 분석 알림 경기 종료 후 1시간 내: 경기 결과 분석 알림 → 하루 2번 자동 전송!
